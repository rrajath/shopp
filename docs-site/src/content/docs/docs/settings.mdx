Two sections, reached from the hamburger drawer.

### Appearance

A System / Light / Dark control. System follows the phone's OS-level theme; Light and Dark override it. Every screenshot in this documentation was captured in both Light and Dark explicitly using this control.

### Behaviour

| Toggle | What it does |
|---|---|
| **Group by label** | Off shows one flat list in the order you added items, instead of sections. |
| **Keep Quick Add open** | On, Enter adds the item and leaves the field ready for the next one — see [Quick Add](/docs/quick-add/). |
| **Confirm before clearing** | Asks before emptying [Recently Completed](/docs/recently-completed/). |

That's the entire screen. There's no export, no import, no font size control, no haptics toggle, and no about page beyond the version string at the bottom.
